# Market icon PNGs (optional override)

Drop **transparent PNG** files here only if you want photo tiles.
**File name = market id** from `institutionalMarkets.ts` (uppercase).

Default UI uses **professional SVG glyphs** (currency / commodity / index silhouettes).
PNG overrides are optional — prefer clean 256×256 art **without text**.

```bash
npm run icons:check
npm run icons:sync
```
